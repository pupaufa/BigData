# Big Data

Repositori ini berisi **kumpulan hasil praktikum mata kuliah Big Data** yang saya kerjakan selama perkuliahan. Setiap pertemuan berisi modul praktikum beserta kode, dataset, dan hasil pengerjaan tugasnya.

## Tentang Repositori

Tujuan repositori ini adalah:

- Mendokumentasikan seluruh hasil praktikum Big Data dari pertemuan ke pertemuan.
- Menjadi arsip belajar dan bahan referensi pribadi.
- Memudahkan saya melacak perkembangan materi, mulai dari dasar hingga penerapan machine learning pada data berskala besar.
